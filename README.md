One pickup line, 90 characters, spoken as if a vending machine were flirting with a passing human: "I'm out of order for everyone else, but for you I'll dispense my last snack and my number." It plays on the machine's own world — out of order, dispensing — stays short and speakable, and stays charming rather than creepy.

## Run it

```sh
python3 main.py
```
